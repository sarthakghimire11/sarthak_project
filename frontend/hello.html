HTML Basics

HTML provides the structure for your webpage. It uses tags like <div>, <p>, and <h1> to organize content.

CSS is used to style the HTML elements with colors, spacing, and layout.

Responsive Design

This layout uses CSS Flexbox and media queries to adjust for different screen sizes. Try resizing your browser window!

Note: On mobile screens, the cards stack vertically. On larger screens, they display side by side.
